# Projects

A collection of programming projects organized by how they were built. The split is intentional: it makes the difference between *what I can do myself* and *what I can do with AI assistance* transparent — both to me and to anyone reading.

---

## Repository Structure

```
.
├── self-built/      # Projects I wrote line by line
├── ai-assisted/     # Projects built with AI tooling
└── README.md
```

### `self-built/`

Projects in this directory are written by me. AI tools (Claude Code) are used **only as a teacher**, not as a code generator — explanations, hints, and code reviews are allowed; generated code is not.

Each project follows the same workflow:
1. Concept and structure planned manually
2. Implementation block by block, written by hand
3. Code review and refactoring with AI feedback
4. Self-test at project end: extending the project without AI assistance

The teacher-mode rules are defined in `self-built/CLAUDE.md`.

### `ai-assisted/`

Projects in this directory are built collaboratively with AI tools. The focus here is on workflow, orchestration, and shipping working software — not on writing every line by hand. These projects demonstrate familiarity with modern AI-assisted development practices.

---

## Why the Split

AI-assisted development is a real and useful skill. So is the ability to write code from scratch. They are not the same skill. Mixing them in one folder makes both harder to evaluate.

Keeping them separate means:
- The `self-built/` directory honestly reflects my programming ability
- The `ai-assisted/` directory honestly reflects what I can ship with current tooling
- Neither directory misrepresents the other
